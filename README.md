Personal Portfolio

📌 Overview

A clean, responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript.
Includes sections for Services, Projects, and Contact, plus social links and smooth scrolling.

✨ Features

Responsive layout optimized for desktop & mobile

Sticky header & smooth navigation

Services cards with hover effects

Projects grid with preview image & “More details” link

Contact cards (phone & email)

Footer with social icons

Lightweight: pure HTML/CSS/JS + Font Awesome for icons

🧩 Tech Stack

HTML5, CSS3, JavaScript (vanilla)

Font Awesome (CDN)

Google Fonts – Poppins
